# Cleanup MailPoet subscribers
Subscribers with status Inactive and Unconfirmed is moved to trash after 1 week  
Subscribers with status Unsubscribed and Bounced is moved to trash after 1 hour  
Subscribers in trash are deleted after 1 day

The plugin also adds **MailPoet > Oprydning** in WordPress admin. The page shows
subscriber counts for every managed status and provides protected manual actions
for moving a status to trash or permanently emptying the trash. WordPress users
and WooCommerce customers are never processed.

## AI transparency
AI tools were used during development of this plugin. All code has been reviewed
and approved by a human.

## Installation
1. Install using the WordPress built-in Plugin installer, or Extract the zip file and drop the contents in the wp-content/plugins/ directory of your WordPress installation.
2. Activate the plugin through the ‘Plugins’ menu in WordPress.
